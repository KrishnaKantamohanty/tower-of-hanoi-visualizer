UNDER THE HOOD

Three rods. One recursive idea.

The visualizer uses actual JavaScript stacks to enforce the rules while the recursive algorithm generates the optimal sequence.

01

How recursion works

To move n discs from A to C, first solve the smaller problem of moving n − 1 discs to B. Move the remaining largest disc to C, then solve again from B to C.

1Move n − 1 discs
A → B
2Move largest disc
A → C
3Move n − 1 discs
B → C

Base case: With zero discs, return; with one, the recursive process emits its direct move.

02

Rods behave like stacks

Each rod is a last-in, first-out (LIFO) stack. Only its top disc is accessible, and a larger disc can never sit on a smaller one.

1 top23 bottomPUSH / POP

Every move pops the source and pushes onto the destination after checking legality.

03

Algorithm pseudocode

solve(n, source, auxiliary, target):
  if n == 0: return
  solve(n-1, source, target, auxiliary)
  move disc n: source → target
  solve(n-1, auxiliary, source, target)

Each recursive call reduces the problem by one disc, then combines the two subproblems around one legal move.

COMPLEXITY

Exponential moves, linear call depth.

The recurrence is T(n) = 2T(n − 1) + 1, giving exactly 2n − 1 moves. Recursion depth is n. The app also stores every move, so its move list uses exponential space.
